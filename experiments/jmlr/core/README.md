# Experiment code (E1-E6): anatomy of pairwise diversity and balanced comparison designs

All estimator experiments are pure NumPy on saved distance tables; only E3/E4 need a GPU.

| File | Purpose |
|---|---|
| `anatomy.py` | Anatomy `d_ij = mu + a_i + a_j + r_ij`, exact variance laws (uniform, Bernoulli-HT, balanced/round-robin), efficiency law, all comparison designs, synthetic families |
| `test_laws.py` | Quick Monte-Carlo check of every exact law (20k draws, 6 families) |
| `e1e2.py` | E1 exact-law validation (`e1`) and E2 matched-budget design comparison (`e2`) |
| `e5e6.py` | E5 design-based confidence intervals (coverage) and E6 distinctiveness recovery |
| `run_e3.py`, `launch_e3.sh`, `launch_w2.sh` | E3: heterogeneous IPPO on VMAS (navigation, dispersion); dumps full SND behavioral distance tables over training (+ real-policy outlier / two-group variants) |
| `e4_zoo.py` | E4: 128-model Fashion-MNIST zoo (4 recipes x 32 seeds), Jensen-Shannon-distance table |
| `analyze_real.py` | Anatomy shares for every saved real table |
| `zoo_large.py` | E4b: exact laws and all designs on the 1,024-model zoo (`SEEDS=256 python e4_zoo.py zoo_fmnist_n1024.npz`) |
| `fixed_bound.py` | Fixed-design spectral bound vs realized error (random simple k-regular graphs and the fixed ring) |
| `launch_w3.sh` | E3 wave 3: three more Dispersion seeds |
| `pool_robustness.py` | Re-estimates the tables of saved final teams from independent rollouts and observation pools (anatomy stability) |
| `fig_*.py`, `figstyle.py` | Figures (vector PDF, DejaVu Serif, Okabe-Ito) |

## Reproduce

```bash
# environment: python>=3.10, numpy, torch (CUDA optional), vmas==1.5.2, matplotlib
python test_laws.py                                   # ~20 s, prints measured/predicted variance ratios
python e1e2.py e1 out/e1_synth.csv                    # E1 synthetic (36 tables x 4 designs x 4 budgets x 3000 draws)
SKIP_SYNTH=1 python e1e2.py e1 out/e1_real.csv "matrices/*.npz" "matrices_init/*.npz" zoo_fmnist.npz
python e1e2.py e2 out/e2_synth.csv                    # E2 synthetic, n=200, 9 designs, k in {1,2,4,8,16}
# Table tab:e2 uses results/jmlr/core/e2_synth_v2.csv, the same run with the fixed
# expander averaged over 100 independently drawn graphs (e2_synth.csv uses one graph).
SKIP_SYNTH=1 python e1e2.py e2 out/e2_real.csv "matrices/*.npz" zoo_fmnist.npz
./launch_e3.sh; ./launch_w2.sh                        # E3 training (writes matrices/, matrices_w2/, matrices_init/)
python e4_zoo.py zoo_fmnist.npz                       # E4 (~15 s on one GPU)
python analyze_real.py "matrices*/*.npz" out/anatomy_real.csv
python e5e6.py out/e5e6.csv zoo_fmnist.npz "matrices/*trained*.npz"
python fig_laws.py figs out/e1_synth.csv out/e1_real_w1.csv out/e1_zoo.csv   # Figure 2 (1,576 cells)
python fig_designs.py figs out/e2_synth_v2.csv      # Figure 7
python fig_ci.py figs out/e5e6.csv
SEEDS=256 python e4_zoo.py zoo_fmnist_n1024.npz && python zoo_large.py zoo_fmnist_n1024.npz out/e4b_zoo1024.csv
python fixed_bound.py out/fixed_bound.csv zoo_fmnist_n1024.npz
```

Saved real tables are in `results/jmlr/matrices/` (VMAS waves 1-3, random-init teams, and the 128-model zoo); the 1,024-model zoo table (8 MB) is regenerated by the command above in about two minutes.

Each saved table `*.npz` has keys `D` (n x n, float64, symmetric, zero diagonal), `n`, `task`,
`iter`, `seed`, `reward`, `kind` (`trained` | `outlier1` | `twogroup` | `zoo`).
`D` for VMAS teams is the SND behavioral distance: mean over a pool of 4096 shared observations
(sampled from the current rollout of all agents) of the 2-Wasserstein distance between the agents'
diagonal-Gaussian action distributions, all policies evaluated on the same observations.
`outlier1`: trained team with agent 0's weights reset to its initialization.
`twogroup`: trained team with the second half of the agents reset to initialization.
